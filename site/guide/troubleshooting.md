# 排障

| 现象 | 原因与处理方式 |
| --- | --- |
| `error: no QQ source: set exactly one of ...` | 未设置 `QQ_DEB_URL`，也未挂载 `/qq/QQ.deb`，详见[首次启动与扫码登录](./first-start) |
| `error: sha256 mismatch: expected ... got ...` | 提供的 deb 文件与当前镜像固定的客户端版本不一致，请更换为指定版本的安装包 |
| `error: both QQ_DEB_URL and the mounted deb ... are set` | 同时配置了下载地址和挂载文件，请只保留其中一种 |
| 实时画面一直停留在二维码界面 | 正常现象，首次登录需由你用手机 QQ 扫码确认 |
| 状态栏显示 **密钥缺失** | 数据库密钥仍在提取中，日志位于宿主机 `./logs/keyx.log`（容器内 `/out/keyx.log`）；驱动会持续等待，提取完成后自动变为 **密钥正常** |
| 状态栏显示 **密钥失效** | 客户端更换了数据库密钥，或解密副本校验失败；请按面板 **QQ** 页面顶部横幅给出的步骤重新提取 |
| 面板页面返回 `502` | `qq` 或 `bot` 容器尚未就绪，可执行 `docker compose logs qq bot` 查看容器启动日志 |
| 模型始终不开启任何轮次 | 先查看面板[概览](./console/)页的 **待处理**：必须同时配置至少一位系统管理员、且至少将一个会话设为 **参与**，模型才会开始轮次 |
| 所有消息都发不出去 | Jev 不可达或未配置 key 时，外发审查会按失败关闭处理并拦截全部发送。请前往[模型与 Jev](./console/models)页面检查 Jev 状态并配置 API key |
| 沙箱内无法安装技能或无法连接外部域名 | 目标域名被出口代理拦截。请前往[安全](./console/safety)页面的 **网络** 卡片查看名单，将需要的域名移至 **放行**（或删除记录让下次请求重新由 Jev 判定） |
| 修改了人设但回复风格没变 | 系统提示词在单个上下文窗口内保持固定；人设修改会在下次窗口轮换后生效，也可点击页面右上角的 **立即轮换** 立即切换窗口 |

## 日志位置

- **面板内的[日志](./console/logs)页：** 汇总驱动动作、模型轮次轨迹、Jev 判定及面板事件，支持按轮次或平铺列表实时筛选。
- **宿主机 `./logs/` 目录：** 存放 `qq` 容器的底层诊断日志（`qq.log`、`keyx.log`、`novnc.log`），**可能包含聊天原文**，切勿直接公开分享。

## 提交问题时建议附带的信息

如需反馈问题，请提供：当前运行的镜像标签（`PERSONAL_BOT_TAG` 或 `latest`）、`docker compose ps` 输出、`./logs/qq.log` 与 `./logs/keyx.log` 末尾日志（**请务必先删去任何聊天内容与账号信息**），以及面板[概览](./console/)页面的脱敏或合成数据截图。
