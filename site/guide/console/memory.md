# 记忆

记忆页是笔记浏览器。笔记由模型自己写、自己改，是它唯一的长期记忆；
每条笔记带一段不超过 200 字的摘要，列表里显示的一律是摘要而不是正文——
扫很多条很便宜，正文只在需要时读。

## 列表与筛选

工具栏：搜索框、状态（活跃 / 已归档 / 全部）、可见性（公开 / 私密 / 机密）
等筛选，高级筛选收在末尾的展开里。结果列表每行一条：标题、摘要、状态、可见性、
所在窗口。点一条打开详情：正文、修订历史（含删除后的墓碑），
以及每次修订的锚点上下文——它来自哪条消息、哪一轮、覆盖哪一段对话。

筛选和打开的笔记都写在网址里，所以一个筛好的列表或一条笔记可以直接链接、直接刷新。
详情里的 常驻 开关是所有者的特权：常驻笔记不论使用情况都进每个新窗口的活跃集合，
模型自己没有办法设它。

## 设置：两个上限

页头的 设置 弹出层管两个数字，改完下一个窗口生效：

| 设置 | 默认 | 含义 |
| --- | --- | --- |
| 活跃笔记上限 | 20 | 一个新窗口里最多保留多少条活跃笔记 |
| 每窗口新笔记 | 10 | 一个窗口里最多写多少条新笔记 |

活跃集合由栈在每个窗口开启时挑：常驻的、这个窗口里写或改的，再按使用情况补满。
其余笔记归档但可检索。机制细节见 [它是怎么工作的](../how-it-works)。
