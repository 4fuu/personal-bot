# 记忆

**记忆** 页面是模型的长期记忆（笔记）浏览器。所有笔记均由模型在日常轮次中自己创建和更新；每条笔记都带有一句不超过 200 字的 **摘要**，模型在搜索笔记以及新窗口初始化时只读取摘要，需要细节时再按需读取正文。

## 搜索、筛选与详情视图

页面顶部的工具栏提供 **全文搜索**（匹配标题与正文）、**状态**（**全部** / **活跃** / **已归档**）和 **可见性**（**全部** / **公开** / **私聊学到的** / **机密**）筛选，右侧的 **高级筛选** 展开后还可按 **关于**（`self`、`person:uid` 或 `conv:id`）、**窗口**（如 `w37`）和 **反链**（如 `msg:7698...`）精确过滤。工具栏下方还会显示最近一条笔记操作记录。

左侧列表展示匹配的笔记：每行显示标题、状态标签（**活跃** / **已归档** / **已删除**）、是否 **常驻**、可见性标签及锚点消息时间。点击任意一条笔记，右侧详情栏会依次展示：

- **常驻开关**：位于详情栏右上角。设为 **常驻** 的笔记在每次窗口轮换时都会无条件进入新窗口的活跃集合；该开关只能由管理员在面板中操作，模型自身没有工具可以修改它。
- **摘要与内容**：当前最新版本的单行摘要与完整正文（已删除的笔记会标注为墓碑修订，其历史版本仍可查阅）。
- **修订历史**：按版本列出每次新建、修改与删除记录，展开 **详情（锚点 / 来源 / 反链）** 可查看该版本对应的窗口、事件记录、所在会话、消息位置、覆盖区间与引用证据。
- **锚点上下文**：点击任意版本的 **查看上下文**，即可并排查看写入该版本前后的自身历史事件、当时的会话消息、引用的证据消息以及覆盖的消息区间；所有引用标签均可直接点击跳转。

当前筛选条件、打开的笔记 ID 与修订版本号都会同步保存在地址栏 URL Hash 中，方便直接复制链接或刷新页面。

## 设置：笔记上限

点击页面右上角的 **设置** 按钮可修改两项配额：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| **活跃笔记上限** | `20` | 每次窗口轮换时最多挑选多少条笔记进入新窗口的活跃集合 |
| **每窗口新笔记** | `10` | 单个上下文窗口内模型最多可以新建多少条笔记（修改已有笔记不占此额度） |

每次开启新窗口时，系统会先放入管理员设为 **常驻** 的笔记和上一窗口刚写改过的笔记，剩余名额按使用度得分从高到低补满（总 token 不超过窗口的 15%）；未入选的笔记自动转为 **已归档**，模型随时可通过搜索工具找回。详见[它是怎么工作的](../how-it-works)。
