# 日志

**日志** 页面提供两种视图来查看运行记录，可通过顶部工具栏的第一个下拉框切换，所有筛选条件均实时同步在地址栏 URL Hash 中：

- **按轮次**：将每一轮展示为一条完整的执行轨迹。每块顶部显示该轮开始时间、所在会话（空闲轮直接显示为 **空闲轮**）、触发摘要，以及插话评估结果、调用工具数、发出气泡数、消耗 token 数与总耗时；点击展开后，按时间顺序展示该轮的输入、模型输出、每次工具调用及其参数与结果、Jev 判定和发送结果。
- **列表**：按时间倒序平铺展示所有记录，涵盖 **驱动**、**机器人** 与 **控制台** 三个来源的事件。

在 **按轮次** 视图下可按会话与具体轮次筛选；切换到 **列表** 视图后，还可按类型（**全部类型** / **Jev** / **发送** / **轮次** / **助手** / **工具调用** / **工具结果** / **写笔记** / **改笔记** / **删笔记** / **轮换** / **提醒** / **错误** / **系统**）、来源（**驱动** / **机器人** / **控制台**）、级别（`action` / `info` / `error`）以及关键词搜索过滤。

## 轮次轨迹中的细节展示

- **工具调用与嵌套脚本：** 一次工具调用和它的返回结果合并展示为一步，包含参数、返回文本（超过 400 字时默认折叠为 **展开全文**）和执行耗时；若该步是 `code_exec` 脚本调用，下方还会逐一列出脚本内部发起的每次嵌套工具调用及其成功 / 失败状态与耗时。
- **模型 token 用量与发送状态：** 每次模型调用步骤都会标注输入、输出及缓存命中 token 数；发送步骤则会逐条列出每个气泡的最终状态（**已发出** / **排队中** / **没发出去** / **未尝试**），并在驱动陆续回报结果时实时更新。
- **Jev 判定与群聊插话明细：** Jev 记录会展示各问题的判定概率；处于 **只记录不生效** 模式的判断还会附带一行说明“如果生效会怎么做”。群聊插话判断直接附在对应轮次记录上，无需单独翻找：展开即可看到 **插话意愿** 概率、**扣分**、最终 **得分**、**阈值** 与 **上限**，以及四项扣分来源（**刚回复过**、**我说得多**、**话痨度低**、**时段安静**）和 Jev 当时看到的上下文统计（近期消息条数、省略的旧消息条数、我的发言占比、他人近 5 分钟消息数、距上次发言分钟数——仅记录统计数字，绝不重复存储聊天原文）。被沉默退避推迟的批次也会单独生成一条记录并标明退避秒数。

日志页面在打开期间会自动轮询刷新；服务重启后也会自动从模型服务拉取近期历史记录并按记录 ID 去重合并。管理面板自身的事件（登录、删除表情包、驱动报错、实时画面连接等）统一归在 **控制台** 来源下。
