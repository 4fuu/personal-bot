# 日志

日志页是同一批记录的两种看法，工具栏第一个控制切换，选择记在网址里：

- **按轮次**：一轮是一条轨迹——它自己的记录开头（输入渲染成的文本、这一轮为什么开始：
  提及、插话、等待到点、定时、空闲轮），它的步骤按追加顺序跟在后面。
  列表是新在前，所以一条轨迹从尾往前读。
- **列表**：平铺的记录流，新的在前。

筛选按类型（轮次、助手、工具调用、工具结果、发送、写 / 改 / 删笔记、轮换、提醒、
Jev、错误、系统）、来源（驱动、机器人、面板）、会话和轮次。

一条工具调用和它的结果读作一步：调用的参数、结果、耗时都在；
`code_exec` 的结果还列出脚本里每次嵌套调用的名字和结局——那是嵌套调用结局的唯一去处。
一次模型调用的 token 用量记在它自己那步上。一条发送记录列出每个气泡的状态
（已发送 / 排队中 / 失败 / 未尝试），结果是驱动程序陆续回报时补上的。

Jev 的记录带概率；只记录不生效 的判断还带一行"它会怎么做"。
插话那道判断骑在轮次自己的记录上：概率、扣分（刚回复过、我说得多、话痨度低、
时段安静，各自多少）、阈值、最后的分数和一句话结论，被沉默退避挡下的批次
也有自己的一条记录和退避时长。

记录也实时流进来；重启后从机器人侧把最近的读回来再接着流，按记录 id 去重。
面板自己的事件（登录、删除表情、驱动错误、实时画面会话）和它们混在同一个列表里，
来源标 面板。
