# 控制台概览

控制台是这台机器的面板：<http://localhost:8080>，用 `CONSOLE_PASSWORD` 登录，
一个会话 cookie，登录前什么都用不了。它是唯一打算发布的服务，也只有它需要被发布。

左侧导航分四组，每组一个主题，一个功能的所有开关和数字都在它自己那一页：

| 分组 | 页面 |
| --- | --- |
| 运行 | 概览、QQ |
| 机器人 | 会话、人设、记忆、表情包、定时 |
| 设置 | 模型、安全、工作区、高级 |
| — | 日志、退出登录 |

状态块常驻在左侧：QQ 登录态、数据库密钥、机器人和 Jev 的灯、窗口 token 水位、
暂停 / 恢复。

## 概览：先看这一页

待处理 只列问题——QQ 没登录、密钥不是 ok、没有主模型、Jev 缺失或不可达、
允许列表是空的、被允许的会话落在读取范围外、机器人被暂停、有技能源更新失败——
每项后面跟着一个能修它的按钮，处理好一项它就消失。没有问题时刻意是空的。

下面三张摘要卡（QQ、机器人、会话）和 最近动态（最近五条轮次、发送和插话记录）。

## QQ：连接与实时画面

连接 卡片一行一个状态：客户端在不在跑、登录状态、版本、数据库密钥
（ok / missing / invalid，不是 ok 时给出重新提取的步骤）、最近同步时间、镜像延迟。
下面的 登录 按钮是手动重试——重启后驱动程序会自己点一次。

实时画面 就是客户端自己的 framebuffer，经控制台代理转出来，VNC 端口不对外暴露。
扫码在这里完成；画面按 1:1 像素画在会滚动的框里，适应窗口 切换到整体缩放。
画面大小由 `SCREEN_W` x `SCREEN_H` 决定（见 [环境变量](../env)）。

## 页面读法

面板刻意做得简单：一个次级账号上的个人助理，没有用户、角色和多账号切换。
每一页都把当前值显示成一行，改它的表单收在弹出层、抽屉或模态里，不摆一长条平铺的表单。
原始 id、ref 和次要字段都在弹出层或"详情"里，一键复制。
