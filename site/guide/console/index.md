# 控制台概览

管理面板默认运行在 <http://localhost:8080>，使用 `CONSOLE_PASSWORD` 登录并通过单个会话 Cookie 维持登录态；未登录状态下所有接口与画面均不可访问。整套实例中只有控制台服务需要对外暴露端口。

左侧导航栏按功能分为三组（外加底部的日志与退出登录），每个功能的开关、阈值和近期判定记录都集中在各自的页面内：

| 分组 | 页面 |
| --- | --- |
| 运行 | 概览、QQ |
| 机器人 | 会话、人设、记忆、表情包、定时 |
| 设置 | 模型、安全、工作区、高级 |
| — | 日志、退出登录 |

导航栏上方常驻一块全局状态区，实时显示：**QQ 登录**、**DB 密钥**、**机器人** 与 **Jev** 四盏状态灯、当前上下文窗口的 token 用量进度条，以及 **暂停** / **恢复** 按钮。

## 概览：日常打开的第一页

页面顶部的 **待处理** 卡片仅在存在异常或缺失配置时出现——例如 QQ 未登录、数据库密钥未就绪、未设置系统管理员、未选择主模型、Jev 未配置 key 或调用失败、未允许任何会话、允许的会话落在驱动读取范围之外、模型已暂停，或存在更新失败的技能源。每一项右侧都带有一个直达对应设置页或立即恢复的按钮；所有问题解决后，该卡片会自动收起。

下方依次排列 **QQ**、**机器人**、**会话** 三张状态摘要卡，以及展示最近 5 条轮次、发送与 Jev 判定记录的 **最近动态** 列表。页面右上角的 **立即轮换** 按钮可在填写理由后通知模型在下一轮边界切换上下文窗口。

## QQ：连接状态与实时画面

**连接** 卡片逐行展示：客户端是否正在运行、当前登录状态、客户端版本号、数据库密钥状态（**正常** / **缺失** / **失效**；非正常时页面顶部会给出重新提取密钥的操作命令）、最近一次同步时间和镜像延迟。卡片右上角的 **登录** 按钮用于在客户端停留在已保存账号页时手动点击登录（容器重启后驱动也会自动点击一次）。

**实时画面** 卡片通过控制台自身代理转发客户端容器的虚拟屏幕画面，VNC 端口不对外暴露。首次扫码登录在此完成；画面默认按 1:1 原始像素在可滚动区域内渲染，点击 **适应窗口** 可切换为按比例整体缩放。虚拟屏幕分辨率由 `compose.yaml` 中的 `SCREEN_W` × `SCREEN_H` 控制（见[环境变量（.env）](../env)）。

## 界面交互设计

控制台专为单账号个人助理设计，不设多用户、角色权限或多账号切换。各个设置页优先以单行摘要展示当前生效值，点击后再通过弹出框、抽屉或对话框修改，避免整页铺满长表单。会话 ID、消息引用（ref）等底层标识符默认折叠在弹出框或“详情”展开项内，点击即可查看并一键复制。
