# 模型与 Jev

模型运行在 [pi](https://pi.dev) 框架之上，**支持 pi 集成的所有模型服务商与模型**。本页面集中管理四项内容：主模型与思考档位、Jev 密钥、LLM 服务商登录，以及网页搜索服务商。

## 主模型

可选模型列表来自 pi 的配置目录（包含内置目录、`pi.dev` 在线目录以及自定义的 `models.json`）。服务启动时会自动拉取一次目录，此后每天后台自动刷新一次（设置 `PI_OFFLINE=1` 时不拉取）；也可随时点击页面右上角的 **刷新目录** 手动更新。

点击当前主模型标签可打开搜索选择框。**主模型必须支持视觉输入**（查看聊天图片和挑选表情包均依赖模型自身视觉能力）；不支持视觉的模型仍会列在列表中，但会标明 **不支持视觉** 且无法选中。主模型旁边的 **思考** 下拉框用于设置推理深度（`关闭`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`），修改后立即生效。

## Jev（出口审查）

[Jev](https://typesafe.ai/) 是 TypeSafe AI 的决策模型。它从不生成聊天回复，只对结构化的是非题（返回 0–1 概率）和分档打分题（返回 0–2 分数）给出判断：包括群聊是否插话、回复前等待多久、回复是否带引用、多个等待会话谁先处理、每条外发气泡是否违规、沙箱请求的新域名是否放行，以及窗口轮换时哪些候选笔记更可能用到。由于每条外发消息都必须经过它审查，一旦 Jev 未设置 key 或调用失败，**外发审查会立即按失败关闭处理，不会发出任何消息**。

该卡片显示 Jev 的当前状态（**正常** / **未设置 key** / **调用失败**）以及 **设置 key** / **更换 key** 按钮。API key 采用只写方式保存在模型服务侧，提交后不会回显给浏览器，也不会出现在日志中。

各项可配置判断的模式、阈值和额外判断标准分布在各自的功能页面上：[会话与策略](./conversations)中的 **回复时机** 与 **引用**、[高级设置](./advanced)中的 **需要程度**（排队），以及[安全](./safety)中的 **出口审查**。

## 服务商（LLM 登录）

列出 pi 注册的所有模型服务商及其支持的认证方式（OAuth 或 API key）：已登录的服务商排在最前，默认展示前 15 项，其余可通过底部 **更多** 按钮搜索查看。点击登录会在对话框中直接转发 pi 的交互提示（如授权链接、设备码或密钥输入框），凭据仅保存在模型服务侧，浏览器不存储任何密钥。无交互登录流程的服务商则会显示 pi 给出的环境变量配置提示。

## 搜索服务商

网页搜索与网页正文读取工具使用的服务商在此配置（当前支持 DeepSeek 与 Parallel），API key 同样只写不读。点击卡片顶部的服务商标签即可在已登录的服务商中切换当前使用的搜索源；若只登录了一家服务商，即使未手动指定，模型也会默认使用它（界面会提示“未选用，当前只有一个已登录的服务商，默认使用它”）。

其中 DeepSeek 与上方的模型服务商共用同一份 API key：在任一处登录或退出登录，另一处都会同步更新。
