# 会话与策略

**会话** 页面决定模型可以看到哪些聊天、在哪些聊天里发言，以及按什么方式发言。表格列出当前账号仍在其中的所有私聊与群聊（已退出的群不再显示，但历史消息仍保留在镜像库中），包含五列：**名称**、**类型**、**状态**、**说话方式** 以及该会话单独 **覆盖** 了多少项默认规则。

## 状态：一个下拉框同时同步两处配置

每行的 **状态** 下拉框修改后立即保存生效，同时更新驱动服务的读取范围与模型的允许列表，从根本上避免“模型允许参与但驱动根本没读取该会话”的配置冲突：

| 状态 | 含义 |
| --- | --- |
| **参与** | 驱动读取并同步该会话，且允许模型访问——模型能看到消息，并按说话方式决定是否回复 |
| **只记录** | 驱动读取并同步到镜像库，可在面板中查看消息，但对模型完全不可见——仅留档、不参与 |
| **不读取** | 驱动不读取该会话的消息，面板列表中仅保留会话名称 |

当[高级设置](./advanced)中的 **读取范围** 设为 **全部会话** 时，驱动默认读取所有会话，因此下拉框中仅提供 **参与** 和 **只记录**；若需排除特定会话，可先在 **高级** 页面将范围切换为 **仅选中的会话**（切换时会自动勾选当前已在读取的会话，不会清空已有镜像）。新部署默认不勾选任何 **参与** 会话，允许列表为空时模型看不到任何聊天内容。

## 说话方式：五种模式

| 说话方式 | 私聊可用 | 群聊可用 | 说明 |
| --- | --- | --- | --- |
| **每条都回** | 是 | — | 收到消息即开启轮次（私聊默认） |
| **只在被叫到时回** | 是 | 是 | 仅在被点名时开启轮次 |
| **被叫到必回，其他时候看情况接话** | — | 是 | 被点名必开轮；平时由 Jev 判断是否主动插话（群聊默认） |
| **全部看情况接话** | — | 是 | 即使被点名也只作为提示交给 Jev 一并评估是否接话 |
| **不说话** | 是 | 是 | 不主动开口，被点名也不回复 |

其中 **被叫到** 包括：在群里 @模型、引用回复模型的消息、提到人设中设置的昵称，或提到下方配置的 **别名** 与 **关键词**。

## 三个独立开关

- **接收新消息**：关闭后，该会话的新消息不再触发任何轮次（排队中的未决批次也会清空）。
- **允许发送**：关闭后，模型无法向该会话发送任何消息或文件。
- **允许被查阅**：关闭后，模型在任何会话中搜索聊天记录或查阅笔记来源时，都无法看到该会话的历史消息。

当 **接收新消息** 或 **允许发送** 处于关闭状态时，**说话方式** 会自动锁定为 **不说话** 并提示原因，避免保存时触发依赖冲突。

## 看情况接话（群聊专属）

当群聊的说话方式设为 **被叫到必回，其他时候看情况接话** 或 **全部看情况接话** 时，会展开以下三项设置：

- **话痨度**：`0` 到 `3` 的滑块（默认 `1`），数值越高越容易主动接话。
- **按时段调整**：按 `HH:MM` 时间段设置 `0`–`2` 的缩放系数（例如深夜调低、晚间调高）；留空则全天保持一致。
- **接话规矩**：用自然语言说明什么话题适合接话、什么情况不要插嘴，直接作为附加准则传给 [Jev](https://typesafe.ai/)。

群里有一批普通消息到达时，先由 [Jev](https://typesafe.ai/) 给出插话意愿概率，系统再根据模型刚在该群发言的时间间隔、近期发言占比、话痨度及当前时段扣减一定分数（批次中有人 @模型时少扣一点）；只 @了其他群成员的消息则直接忽略。如果连续两批及以上没有发言，该群下一次插话判断会自动推迟（消息继续合并而不丢弃），一旦有人 @模型、叫它名字、说出唤醒词或短时间内消息密集涌入，推迟会立即结束。

## 算作叫到我的词

可为模板或单个会话配置 **别名**（其他称呼）和 **关键词**（聊天中出现即视为点名），输入后按回车添加。

## 高级：回复时机与引用判断

展开底部 **高级** 区域可配置两项由 [Jev](https://typesafe.ai/) 驱动的判断：

| 判断项 | 作用 | 阈值范围 |
| --- | --- | --- |
| **回复时机** | 开启轮次前是否再多等片刻，看看对方有没有后文 | `0`–`2`（达到多少分才开始等待） |
| **引用** | 回复的首条气泡是否带上对原消息的引用（距今超过 30 条或 10 分钟的消息强制引用） | `0`–`1` |

每项判断均可设为 **关闭**（不调用 Jev）、**只记录不生效**（调用 Jev 并将结果记入日志，但实际仍按默认规则立即回复 / 不额外引用——所有新上线的判断默认处于此模式）或 **启用**（在规则边界内按 Jev 的结论执行），并可填写 **额外判断** 补充自定义标准。**回复时机** 还可分别设置 **私聊上限（秒）**（默认 `30` 秒）与 **群上限（秒）**（默认 `60` 秒）；被点名或管理员发话时固定最多等待 `30` 秒。

## 默认规则抽屉与单会话抽屉

点击页面右上角的 **默认规则** 可打开模板抽屉，分别编辑 **私聊** 与 **群** 的默认策略，并在 **群** 页签底部调整全局 **插话** 参数（阈值 `0`–`1`、最大扣分 `0`–`1` 及额外判断；将最大扣分设为 `0` 表示完全按 Jev 的概率决定）。

点击表格中的任意一行则会打开该会话的专属抽屉，包含四个页签：

- **规则**：仅对状态为 **参与** 的会话开放编辑。每项设置旁均标明 **默认** 或 **覆盖**，点击 **恢复默认** 即可清除单项覆盖。
- **消息**：预览该会话最近 20 条消息，点击 **打开全部** 可进入该会话的完整消息浏览子页。
- **记录**：展示该会话近期触发、插话与审查相关的记录。
- **唤醒词**：只读展示模型在结束轮次时留下的唤醒词及剩余有效时间（最长 6 小时，该会话开启下一轮时自动清空）。
