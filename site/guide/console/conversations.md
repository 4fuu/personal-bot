# 会话与策略

会话页回答一个问题：模型跟谁说话。表格列出镜像里的会话，每行五列：名称、类型、
**状态**、**说话方式**，以及这一行覆盖了多少项规则。改完立即生效，页面没有保存条。

## 状态：三个值，一次写两处

| 状态 | 含义 |
| --- | --- |
| 参与 | 驱动读它，机器人也允许看到它——会读，也可能回复 |
| 只记录 | 驱动读它、面板里看得见，但机器人看不到——留档，不参与 |
| 不读取 | 驱动直接丢掉，面板里只显示名字 |

状态同时写两个存储：驱动程序的读取范围和机器人的允许列表，所以"机器人允许但驱动不读"
这种半状态选不出来。范围模式在 [高级](./advanced) 的 读取范围 卡片里；停在 全部会话 时
不提供 不读取，切到 仅选中的会话 会用驱动今天在读的会话把选择种子好。
什么都不允许是默认：一张空允许列表意味着机器人一个会话都看不到。

## 说话方式：五种

| 模式 | 私聊 | 群 |
| --- | --- | --- |
| 每条都回 | 有 | |
| 只在被叫到时回 | 有 | 有 |
| 被叫到必回，其他时候看情况接话 | | 有 |
| 全部看情况接话 | | 有 |
| 不说话 | 有 | 有 |

被叫到 指：@它、回复它的消息、提到它的昵称，或提到下面设的别名 / 关键词。

## 三个开关

- **接收新消息**：关掉后，这里的新消息不再开始任何一轮。
- **允许发送**：关掉后，机器人不能往这个会话发消息。
- **允许被查阅**：关掉后，机器人在任何会话里检索、写笔记都看不到这里的历史。

接收 或 允许发送 关着时，说话方式 锁在 不说话 并说明原因——不会让一次保存失败在依赖规则上。

## 看情况接话（群）

后两种群模式才有的块：

- **话痨度**：0 到 3 的滑杆，越大越爱接话；按时段和规矩仍然管着它。
- **按时段调整**：按 `HH:MM` 时间段缩放话痨度，每段一个 0-2 的系数，留空全天不变。
- **接话规矩**：什么时候适合插话、什么时候别插，判断模型会参考这段自由文本。

插不插由 [Jev](https://typesafe.ai/) 打分，栈再按"它是不是刚在这里说过话"扣一点分、被 @ 时少扣一点；
只跟别人说话的批次不去接。连着几批没开口后，下一次判断会推迟（消息暂存不丢），
@ 它、叫它名字、唤醒词或消息突然变多都会立刻结束推迟。

## 算作叫到我的词

**别名**（别的称呼）和 **关键词**（聊天里出现就算被叫到），回车添加，可多个。

## 高级：两个 Jev 判断

| 判断 | 管什么 | 阈值 |
| --- | --- | --- |
| 回复时机 | 开轮前等多久再答 | 0-2：分数到多少才值得等 |
| 引用 | 回答时要不要带上被回复的那条 | 0-1 |

每个判断有三种模式：**关闭**（不问）、**只记录不生效**（问，把答案记在日志里，
规则默认照旧行动——每个新判断都从这里上线）、**启用**（在规则边界内按答案行动）。
阈值之外还能填一段 额外判断，给这个判断加自己的标准。回复时机 另带两个上限：
私聊和群里最多等多久（默认 30 秒 / 60 秒），被叫到或管理员说话时最多 30 秒。

## 默认规则 与单个会话

默认规则 抽屉里是私聊和群两套模板，加上插话那道判断（阈值 0-1、最大扣分 0-1、
额外判断）：填 0 表示完全听 Jev 的。点一个会话打开它的抽屉，四个页签：

- **规则**：上面每一项，逐行标着 默认 / 覆盖，可 恢复默认；覆盖只写它改过的字段。
- **消息**：最近的来往，打开全部 进这一会话的消息子页。
- **记录**：这个会话最近的判断与发送。
- **唤醒词**：只读。模型安静结束一轮时留下的词，六小时内出现即开启新一轮，
  下一轮开始后清空。
