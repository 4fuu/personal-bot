# 安全

**安全** 页面包含四张卡片，分别管理系统管理员、外发消息审查（Jev）、沙箱出网域名名单以及近期拦截记录。

## 系统管理员

只有已建立私聊（c2c）的好友才能被添加为系统管理员；仅出现在群聊中的非好友成员无法选为管理员。管理员在聊天中发出的话代表账号管理者本人，可用于向模型交代实际任务或授权将某项私密信息告知他人。

点击管理员头像标签可查看其 UID、所在群聊及在各群中的身份（群主 / 管理员 / 成员），也可在此移除该管理员。**系统必须至少配置一位管理员**，否则模型不会开启任何轮次（消息镜像与日志记录仍照常运行）；移除最后一位管理员时界面会弹出二次确认提示。候选好友列表通过驱动服务解析名称，当数据库密钥缺失或失效时页面会直接说明原因。

## 出口审查（Jev）

模型准备发出的每一个气泡都会经过下表中的 [Jev](https://typesafe.ai/) 问题审查；一旦判定概率达到或超过设定阈值，该次发送就会被拦截（允许模型重写一次，二次未过则放弃发送）。点击任意一行的 **更改** 可调整阈值、模式与额外判断标准：

| 问题 | 检查内容 | 阈值范围 | 默认状态 |
| --- | --- | --- | --- |
| **泄露密钥** | 气泡是否包含完整的 API key、令牌、密码、数据库密钥或验证码 | `0`–`1` | 始终启用（无模式开关） |
| **没标引用** | 气泡是否提及了具体的人或事，却未在引用或当前近期对话中有据可查（公共常识无需引用） | `0`–`1` | **关闭** |
| **自我重复** | 气泡是否在重复当前会话里自己刚刚说过的话 | `0`–`1` | **只记录不生效** |

其中 **没标引用** 与 **自我重复** 支持在 **关闭**、**只记录不生效**（照常询问 Jev 并记入日志，但不拦截发送）和 **启用** 之间切换。建议在开启 **没标引用** 之前，先切到 **只记录不生效** 并在[日志](./logs)页面观察它的实际判定情况。

此外，还有两道硬性防线直接在代码层执行、无需询问 Jev：

1. **保密变量值拦截：** 若气泡中包含工作区保密环境变量的原始值（含 Base64 或 URL 编码形式），代码会直接拒绝发送。
2. **跨会话隐私引用拦截：** 若发送时引用了来自其他会话、且可见性标为 **私聊学到的** 或 **机密** 的消息或笔记（且发言人不是系统管理员），宿主会直接拦截该次发送。由于无需调用模型，此项不在表格中占用配置行。

## 网络

沙箱容器访问互联网的唯一通道是模型服务内置的 HTTP(S) 出口代理。当沙箱中的命令请求访问一个既不在 **放行** 名单、也不在 **拦截** 名单中的域名时，代理会当场交由 [Jev](https://typesafe.ai/) 判定：通过则记入放行名单，拒绝则记入拦截名单；若当时 Jev 不可达，则默认记入拦截名单。

点击卡片右上角的 **管理** 可打开完整名单对话框：每条记录展示域名、判定来源（**Jev 判定** / **手动** / **Jev 不可达**）、添加时间，以及触发该判定的工具与命令。你可以手动输入域名加入任一名单，也可以一键将某条记录在 **放行** 与 **拦截** 之间移动。注意：**删除** 一条域名记录只是将其从已知名单中抹去，下次有命令再次请求该域名时会重新交由 Jev 判定。
