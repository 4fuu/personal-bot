# 工作区

工作区页三张卡片：环境变量、Skills、MCP 服务器。前两个是沙箱的命令能碰到的东西，
第三个是模型能调用的外部函数。

## 环境变量

沙箱里每条命令都会带上这些变量。一条变量有名字和 明文 / 保密 两种；
保密值只写不读，任何输出里的保密值都会被替换成 `[已隐藏:名字]`，
带着保密值的消息在发出去之前就被代码拦下，不问 Jev。

- 名字必须是 shell 变量名（字母开头，64 字符以内）。
- 沙箱自己的固定项不能被覆盖：`PATH`、`HOME`、代理设置、`LD_PRELOAD` 等——
  它们是宿主该定的，不是模型该定的，页面会说明是哪一条。
- 保密值至少 8 个字符，这样脱敏才匹配不到普通文本。

改动对下一条命令生效，不需要重建任何容器。

## Skills

技能装在 `/workspace/skills` 里，**模型可以自己读、自己改、自己装**；
这一卡片管的是"源"：一个地址，安装程序按周期把它拉下来更新。

- 地址可以是 GitHub 简写（`owner/repo`）或 `https://` 的 git 地址；
  SSH 地址、本地路径、指向单个文件的地址都会被拒绝并说明原因
  （代理只隧道 443，沙箱也看不到工作区以外的东西）。
- 周期 1 到 365 天，默认 7。
- 每行显示装到哪个 commit、上次更新于何时、正常 / 失败；失败的带原因，
  同时出现在 概览 的 待处理 里。立即更新 手动跑一次，移除 只去掉这个源，
  它装好的技能留在工作区。

## MCP 服务器

模型只能在 `code_exec` 里用 `tools["服务器.函数"](args)` 调用 MCP 服务器；
函数名先让模型用 `tool_search` 查。系统提示里每个服务器占一行，随窗口冻结，
所以停用一个服务器或一个函数不会改动这一行——调用会被拒绝并说明原因。

- 添加 / 编辑 / 停用 / 删除，一行一个服务器：状态（已连接 / 需要授权 / 错误）、
  函数个数、其中停用几个、传输方式、授权状态。
- 行展开就是这个服务器提供的函数：名字、描述、参数、一个开关。
- 传输方式三种：Streamable HTTP、SSE、stdio（stdio 的在沙箱里跑，出网只走代理）。
- 认证三种：无、请求头（头的值填一个 [环境变量](#环境变量) 的名字，连接时读取，
  不落库、不返回）、OAuth。
- 服务器名是小写标识符，脚本里写起来不用加引号；地址、命令、client id 这些
  技术值只接受英文字母、数字和标点，表单在输入框下面写清规则，不达标存不下去。

OAuth 的授权流程单独一页：[MCP 客户端](../mcp)。
