# 工作区

**工作区** 页面包含三张卡片：**环境变量**、**Skills** 与 **MCP 服务器**。前两项供沙箱内的命令与工具使用，第三项用于为模型接入外部 MCP 函数。

## 环境变量

沙箱中执行的每条命令都会自动注入这里配置的环境变量。每个变量可设为 **保密** 或 **明文** 两种类型（默认 **保密**）：

- **保密变量只写不读：** 变量值保存在模型服务侧的密钥目录中，面板和日志只显示变量名、绝不回显变量值。命令输出、搜索结果或工具返回值中一旦出现保密变量的原始值（包括其 Base64 和 URL 编码形式），都会在进入模型上下文和日志前被自动替换为 `[已隐藏:变量名]`；若待发送的聊天消息中含有保密变量值，会在调用 Jev 前直接由代码拦截。
- **命名与长度规则：** 变量名必须符合 Shell 标识符规范（以英文字母或下划线开头，仅含字母、数字和下划线，最长 64 个字符）。为防止脱敏器误伤日常普通短词，**保密** 变量的值长度至少为 8 个字符。
- **保留变量不可覆盖：** 沙箱自身的宿主环境变量（如 `PATH`、`HOME`、代理配置 `HTTP_PROXY` / `HTTPS_PROXY`、`LD_PRELOAD`、`NODE_OPTIONS` 等）不允许在此覆盖，界面会直接提示原因。

新增、修改或删除环境变量会立即对下一条沙箱命令生效，无需重启任何容器。

## Skills

技能文件安装在共享工作区的 `/workspace/skills` 目录下，**模型在轮次中可以自行读取、修改或安装技能**。本卡片用于管理“技能源”——由系统按设定周期在沙箱内自动拉取和更新的 Git 仓库：

- **支持地址格式：** GitHub 简写（`owner/repo`）或 `http(s)://` 开头的 Git 仓库地址。由于沙箱仅能通过 HTTP(S) 代理出网且无法访问宿主机其他路径，SSH 地址、本地路径以及直接指向单个文件的下载链接均会被拒绝并提示原因。
- **自动更新周期：** 可选 1、3、7（默认）、14、30 或 90 天（API 支持 1–365 天）。添加技能源时会自动将其 Git 域名与 `registry.npmjs.org` 加入沙箱出口放行名单并立即开始安装。
- **状态与操作：** 每行显示技能源地址、当前安装的 Git Commit、上次更新时间及状态（正常或失败原因；更新失败的技能源也会出现在[概览](./)页的 **待处理** 中）。点击 **立即更新** 可手动触发一次更新；点击 **删除** 仅移除该更新源，已安装到 `/workspace/skills` 中的文件仍保留在工作区内。

## MCP 服务器

模型在脚本中按需检索并调用已接入的 MCP 服务器函数。系统提示词中每个 MCP 服务器占一行说明，并在当前上下文窗口内保持固定；因此新增或删除服务器会在下一个窗口生效，而**停用某个服务器或单个函数会立即生效**——窗口内再次调用该函数时会被宿主直接拒绝并说明原因，无需重写系统提示词而破坏缓存。

- **服务器列表：** 每行展示服务器名称、描述、状态标签（**已连接** / **需要授权** / **出错** / **未检查** / **已停用**）、已发现的函数数量（及其中已停用的数量）、传输方式和授权状态，提供 **授权**（仅 OAuth 2.1）、**编辑**、**停用** / **启用** 和 **删除** 操作。
- **按函数单独开关：** 点击服务器行左侧的展开按钮，即可查看该服务器最近一次成功列出的全部函数（函数名、描述、参数类型及是否必填），并可通过右侧开关单独启用或停用任意函数。
- **三种传输方式：** `Streamable HTTP`、`HTTP+SSE（旧）` 和 `stdio（在沙箱里跑）`（`stdio` 服务在沙箱容器内运行，其网络请求同样只走沙箱出口代理）。
- **三种认证方式：** **不用认证**、**静态请求头**（请求头的值填写上方已保存的**环境变量名称**，连接时从密钥库读取，绝不把明文令牌存入数据库或返回前端）和 **OAuth 2.1**。
- **输入校验：** 服务器名称固定为小写字母开头的小写字母、数字与下划线组合（最长 32 个字符），方便在脚本中直接引用；地址、命令、参数、Client ID 等技术字段仅限英文字符、数字与标点，输入框下方会实时提示校验规则。

关于 OAuth 2.1 的客户端注册模式与授权步骤，详见[MCP 客户端（OAuth）](../mcp)。
