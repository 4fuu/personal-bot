# 高级设置

**高级** 页面集中放置平时较少改动的全局参数与底层开关，共分为六张卡片。

## 读取范围

控制驱动服务从客户端数据库同步哪些会话到镜像库中，作为模型允许列表的最外层边界，由驱动服务强制执行：

- **全部会话**（默认）：驱动同步所有会话，具体允许模型参与哪些会话在[会话与策略](./conversations)页面通过 **参与** / **只记录** 控制。
- **仅选中的会话**：驱动仅同步被选中的会话。从 **全部会话** 切换到 **仅选中的会话** 时，系统会自动将当前已在读取的会话填入选中列表，不会导致现有镜像数据被一并清空；具体勾选哪些会话同样在[会话与策略](./conversations)页面的 **状态** 列调整。

## 发送节奏

所有外发消息均经过驱动服务的单一动作队列，任何调用方都无法绕过。最小间隔保证两次操作之间不会紧贴；字符预算则按配置的打字速率对每条消息计费（中文与其他字符共用同一个会话滑动窗口预算，并附加 ±15% 随机抖动），超出预算的发送会自动等待窗口腾出余量：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| **最小间隔** | `3` 秒 | 两次操作之间的最短间隔时间 |
| **中文速度** | `240` 字/分钟 | 中文字符（含中文标点与全角字符）的计费速率 |
| **其他字符速度** | `960` 字符/分钟 | 英文、数字、Emoji、空格等其他字符的计费速率 |
| **图片和贴纸** | `10` 字 | 发送一张图片、表情包或文件折算的中文字符数 |
| **小黄脸** | `2` 字 | 发送一个客户端内置小黄脸表情折算的中文字符数 |
| **统计窗口** | `60` 秒 | 计算单会话字符预算的滑动时间窗口；设为 `0` 则仅保留最小间隔限制 |
| **最长等待** | `900` 秒 | 单条发送因等待字符预算允许排队的时长上限，超出则直接报错 |

**建议保持默认发送节奏：** 自动化驱动桌面客户端时，发送行为本身与接入方式同样影响账号风控。

## 合并消息

控制同一会话中连续到达的消息在开启一轮前等待合并的秒数：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| **静默等待** | `2` 秒 | 会话安静下来、无人继续发言后等待多久再开轮 |
| **轮次进行中** | `5` 秒 | 上一轮尚未结束时等待多久 |
| **同一人连续发** | `2` 秒 | 同一个人连续发送多条消息时等待多久 |
| **换人发** | `0.5` 秒 | 另一个人接话发言时等待多久 |
| **被叫到的上限** | `1` 秒 | 批次中包含点名（@、回复、昵称等）时最多等待多久 |
| **一批的上限** | `8` 秒 | 从本批第一条消息到达算起的总等待时长上限 |

## 排队

当多个会话同时等待模型处理时，决定优先响应哪一个（被点名与私聊始终优先于群聊主动插话与唤醒）：

- **饿等上限**（默认 `120` 秒）：排队等待超过该秒数的会话无条件优先处理，不受 Jev 排序影响。
- **需要程度**：由 [Jev](https://typesafe.ai/) 按“该会话此刻有多迫切需要回复”打分（阈值范围 `0`–`2`），将高分会话排到前面。支持 **关闭**、**只记录不生效**（默认）与 **启用** 三种模式，并可补充 **额外判断**。

## 空闲轮

设置 **空闲轮间隔（分钟）**（默认 `0`，即关闭；最大 `1440` 分钟即 1 天）。当距离上一轮开始已满设定分钟数、且期间没有任何新轮次时，模型会自动开启一轮不属于任何会话的自由时间，可用于搜索感兴趣的话题、阅读网页、使用工具或整理笔记，也可直接静默结束。任何类型的轮次（含空闲轮自身）开始都会重置计时器；当模型处于暂停状态、尚未配置系统管理员或当前有轮次正在运行 / 排队时，不会开启空闲轮。

## 工具

管理 `code_exec` 开关（默认 **开**）。开启时，低频检索与扩展工具会收敛到 `code_exec` 脚本工具背后，由模型编写简短的 JavaScript 一次组合调用多个工具；若所选主模型不擅长编写脚本，可将其关闭以回退为全部工具直接暴露给模型。修改在下一次窗口轮换后生效。
