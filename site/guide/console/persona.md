# 人设

**人设** 页面集中管理写入模型系统提示词（System Prompt）的全部身份设定。页面上方为四个分类页签，底部配有统一的变更保存栏：

| 页签 | 包含字段 |
| --- | --- |
| **基本** | **昵称**（模型在群聊和私聊中的自称）、**别名**（输入后按回车添加，同时用于点名识别与唤醒判断） |
| **风格** | **性格**（身份背景与性格特征）、**行为风格**（何时发言、主动程度、如何避免抢话）、**回复风格**（用词习惯、句子长短、标点偏好） |
| **示例** | **示例对话**：按“对方一句、你一句”成对添加，用于固定说话语气 |
| **禁忌** | **禁忌话题**：按回车添加，写入系统提示词的“绝不提及”列表中，约束模型绝不主动谈及这些内容 |

## 修改何时生效

为了保证模型服务商的提示词缓存持续命中，系统提示词在同一个上下文窗口打开期间保持冻结。因此，保存人设修改后，新设定默认会在**下一次窗口轮换**时生效（页签上方的常驻提示横幅会说明这一点）。

如果希望新设定立即生效，可在保存后点击页面右上角的 **立即轮换**：在弹出的对话框中填写本次手动轮换的理由（必填，最多 500 字），系统就会在下一轮边界开启新窗口并加载新的人设，所填理由也会记录在日志和新窗口开头。

注意：模型自己调用窗口轮换工具时，必须等当前窗口 token 用量达到 60% 以上且写好交接备忘才被允许；而管理员在面板点击 **立即轮换** 不受 60% 用量限制，随时可以执行（详见[它是怎么工作的](../how-it-works)）。
