# 人设

人设页是那份长的：四个页签、一个保存条，写进系统提示的身份字段都在这里。

| 页签 | 字段 |
| --- | --- |
| 基本 | 昵称（群里怎么称呼它）、别名（回车添加，参与 @判定和唤醒判断） |
| 风格 | 性格（它是谁：背景、性格）、行为风格（什么时候说话、主动性、不抢话）、回复风格（措辞、长度、标点） |
| 示例 | 示例对话：用户一句、助手一句，成对添加 |
| 禁忌 | 禁忌话题：这些内容同时交给出口审查使用 |

## 改动什么时候生效

系统提示在整个上下文窗口里是冻结的，所以人设改动在**下一次轮换**时生效——
横幅常驻在页签上方说明这件事。想立刻生效就按页头的 立即轮换：它会要一个理由
（必填，说明为什么手动轮换），理由写进新窗口的开场，也记在日志里。

手动轮换会丢掉当前窗口的上下文，所以它不在窗口不到六成满时被允许——
那是模型自己的交接该做的事，见 [它是怎么工作的](../how-it-works)。
