# 环境变量（.env）

`.env` 是 `compose.yaml` 旁边的一个纯 env 文件：`KEY=value` 行和 `#` 注释，没有别的。
复制 `.env.example` 改成 `.env` 再填。下面是全部变量。

## 必须填

| 变量 | 含义 |
| --- | --- |
| `CONSOLE_PASSWORD` | 面板密码。它是面板前面唯一的一道门，请设长一点 |
| `DRIVER_TOKEN` | 内部令牌之一，驱动程序没有它拒绝启动；控制台和机器人用它调驱动程序 |
| `BOT_TOKEN` | 内部令牌之一，控制台持有它，永远不下发给浏览器 |
| `SANDBOX_EXEC_TOKEN` | 内部令牌之一，机器人用它调沙箱；沙箱里只有 root 能读到它 |

三个令牌用 `openssl rand -hex 32` 生成。它们不离开这套栈：每个服务只拿到自己需要的那些。

## QQ 来源：二选一

| 变量 | 含义 |
| --- | --- |
| `QQ_DEB_URL` | `qq` 容器下载固定版本的地址。留空并改成挂载 deb，就走文件来源 |

两个都给了，容器会拒绝启动并说明；都没给也一样。细节见
[首次启动](./first-start)。

## 可选

| 变量 | 默认 | 含义 |
| --- | --- | --- |
| `PI_OFFLINE` | `0` | `1` 关闭 pi 拉取模型目录，用于完全离线的运行 |
| `KEYX_TIMEOUT_S` | `900` | 首次启动等数据库密钥提取多久。实测提取最多约 8 分钟，机器慢就调大；超时不致命，驱动程序会继续等 |
| `PERSONAL_BOT_TAG` | 空（`latest`） | 要运行的镜像 tag。留空用最新发布；设为 `v2026.1025.0` 这样的 tag 即固定版本 |

## 模型自己的设置不在环境变量里

用哪个模型、谁可以跟它说话、它能记住什么、它的命令可以访问哪些域名、消息怎么合并、
排队怎么排——全都在 [控制台](./console/)里，改完即生效，不需要动 `.env`，也不需要重建容器。

`compose.yaml` 里还有两个屏幕相关的变量（`SCREEN_W`、`SCREEN_H`，默认 1280x800），
它们决定实时画面的大小；改它们要同时改 `compose.yaml` 并重建 qq 镜像。
